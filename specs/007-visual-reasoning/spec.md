## Requirements

- FR-002: A readable focused map and keyboard-accessible list preserve exploration context, show relationship meanings and annotation roles/review states, count hidden examples and allow expansion.

- FR-004: Audit starter coverage; add strong eligible varied examples where found, prioritising contextual incongruity, figure-ground ambiguity, metaphor and juxtaposition. Aim for five each without weakening evidence or rights. Record exact unmet gaps and searches.
- FR-005: Inspect accepted pixels, preserve official rights evidence/checking date, attribution and redistribution permission, apply existing independent model review where available, report review status honestly. Clean import and credits must agree.
- FR-006: Improve ordinary-language interpretation with deterministic rules first, preserve explicit choices and original adviser text, remove instruction terms from searches, allow direct corrections and avoid hard filtering on inferred tags.
- FR-007: Freeze builder-labelled development and held-out evaluations before tuning; compare old/new precision and recall with raw counts and candidate retrieval. Include names, paraphrases, ambiguity, multiple mechanisms, negation, conflicts, subjects and no-technique cases.
- FR-008: Preserve editorial identity, local security, rights policy, existing CLIs, corrections and data compatibility. No additional services or model calls for navigation.
- FR-009: Verify offline tests, typecheck, production build, import/credits, evaluations, bounded available live checks and real Playwright desktop/mobile/keyboard journeys; independently review and fix material findings.
- FR-010: Update user/build/release documentation, bump minor version and build a local source-matching distributable. No push/publish or real-library writes.

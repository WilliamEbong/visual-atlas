# Visual Atlas — quick start

**What it is:** a library of free-to-use images, filed by the visual techniques that make them work.
It finds images for you, checks that you may use them, explains why they may work, and helps you
apply the ideas to your own projects.

## 1. Install (Windows, about five minutes, once)

1. Download the newest `VisualAtlas-….zip` from
   [Releases](https://github.com/WilliamEbong/visual-atlas/releases/latest).
2. Right-click the zip → **Properties** → tick **Unblock** → **OK**. Extract it to a folder you keep, with a short path
   (for example `C:\VisualAtlas`; very deep folders can exceed Windows's path-length limit).
3. Double-click **Install Visual Atlas**. When it says *All done*, Visual Atlas opens.

From then on, double-click the **Visual Atlas** icon on your Desktop or in the Start menu. Close the
window when you are finished.

## 2. Look around (no setup needed)

The starter library is already there. Open any image to see **what you can see**, **why it may work**,
and **usage and credits**. Try **Explore** to start from a goal such as *Make one thing stand out*.

## 3. Let it find images for you (optional, needs an assistant)

Visual Atlas uses the AI assistant you already have, with your own account. Your library stays on your
computer; each AI step sends the picture or text it needs to that assistant's service (OpenAI for Codex,
Anthropic for Claude Code).

- **Codex** (ChatGPT plan): install, then run `codex login` once in a terminal, or
- **Claude Code** (Claude plan): install, then run `claude` once in a terminal and sign in.

Check **Settings → AI setup** shows *Ready*. Then:

1. **Find images** → describe what you want to see → **Find images**.
2. Watch it go: Searching → Checking permissions → Analyzing → Ready.
3. New images appear in the library with their credits.

## 4. Use them

- **✓ Confirm / ✕ Reject / Edit** any reading — your decision always wins.
- **Save to collection**, then **Export zip** with credits.
- Pick two to four images with **+ Compare**.
- **My project** → describe your project → **Suggest directions** grounded in your images.

## 5. Keep it safe

**Settings → Back up now.** Your library lives in `%USERPROFILE%\VisualAtlas`.
